JSON Schema definition for the data structure returned by the ScotAccount service

ScotAccount Service Schema

The current schema for the scotaccount service is listed below. This describes the data and structure the service will return from the verified attributes endpoint.

Schema Overview

This JSON Schema (draft-07) defines the structure of the claimsToken JWT payload returned when calling the attributes endpoint. The schema includes:

  • JWT Standard Claims: iss (issuer), sub (subject), and iat (issued at time)
  • Verified Claims Array: Contains verification details and claims for each requested scope
  • Scope-Specific Claims: Different claim structures based on the scope (scotaccount.address, scotaccount.gpg45.medium, or scotaccount.email)
